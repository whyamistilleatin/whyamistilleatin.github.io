# 个人主页

这是一个可直接用于 GitHub Pages 的静态个人主页，基于简历内容整理为 Technical Writer / Localization Specialist 方向的作品集入口。

## 文件结构

- `index.html`：网页内容
- `style.css`：视觉样式与响应式布局
- `script.js`：导航菜单与年份
- `assets/hero-workspace.png`：首屏视觉图

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库：`你的用户名.github.io`
2. 上传本项目全部文件到仓库根目录
3. 进入仓库 `Settings` -> `Pages`
4. 选择 `Deploy from a branch`
5. Branch 选择 `main`，Folder 选择 `/root`
6. 保存后访问：`https://你的用户名.github.io`

- 有正式头像或作品截图后，可以替换 `assets/hero-workspace.png`
